# Funkcja: Przeglądanie przedmiotów

**Cel:** student szybko znajduje obieraka i widzi, jak jest oceniany.

## Zadania

- [ ] `BE` `GET /przedmioty` - lista ze średnią oceną i liczbą opinii.
- [ ] `BE` `GET /przedmioty/{id}` - szczegóły + opinie opublikowane + rozkład ocen.
- [ ] `BE` Średnia i rozkład liczone tylko z opinii opublikowanych.
- [ ] `FE` Ekran listy przedmiotów: nazwa, średnia, liczba opinii.
- [ ] `FE` Wyszukiwarka / filtr po nazwie.
- [ ] `FE` Ekran szczegółów: opis, średnia, rozkład ocen, lista opinii.
- [ ] `FE` Stany ładowania i stan pusty (przedmiot bez opinii).

## Decyzje do ustalenia

- [ ] Jakie pola przedmiotu pokazujemy (nazwa, prowadzący, kod, semestr, opis).
